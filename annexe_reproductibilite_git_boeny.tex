\chapter{Gestion de version et reproductibilité}
\label{annexe:reproductibilite_git}

\section{Principes retenus}

La reproductibilité des résultats (chapitre 3) repose sur trois piliers
complémentaires :

\begin{enumerate}
  \item \textbf{Graine fixe} : \texttt{SEED = 1}, \texttt{random\_state = 1},
        \texttt{nstart = 25} — les partitions K=6 et les règles (lift max 34,9)
        sont strictement identiques à chaque exécution.
  \item \textbf{Données traitées versionnées} : les fichiers intermédiaires
        (profils, matrices, trajectoires lissées) sont conservés dans le dépôt
        Git pour traçabilité et comparaison.
  \item \textbf{Versionnage systématique} : chaque étape du pipeline constitue
        un \emph{commit} documenté — l'historique Git sert de \emph{journal de
        bord méthodologique}.
\end{enumerate}
